# ADR-003: Foundation Freeze Policy
**Status:** APPROVED  
**Date:** 2 Juli 2026  
**Context:** Pembangunan modul-modul kognitif domain yang cepat sering kali menggoda pengembang untuk merekayasa ulang komponen inti platform, merusak stabilitas baseline.  
**Decision:** Mengunci baseline Foundation `UAI-FB-1.0` secara mutlak. Perubahan arsitektur dasar dilarang keras, kecuali melalui pengajuan formal RFC -> ACR -> ADR dan kenaikan nomor baseline mayor baru.  
**Consequences:** Menjamin kestabilan operasional ekosistem runtime hilir.
