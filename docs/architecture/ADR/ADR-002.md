# ADR-002: Stateless Execution Runtime
**Status:** APPROVED  
**Date:** 2 Juli 2026  
**Context:** Pemicuan kompilasi fisik dari Blueprint sering kali mengalami anomali memori (*memory leak*), ketidakkonsistenan build, dan penumpukan cache domain jika compiler menyimpan status internal.  
**Decision:** `ExecutionRuntime` wajib bersifat stateless murni. Engine dilarang menyimpan cache kognitif, ingatan state, preferensi, atau data memori domain. Setiap pemanggilan harus mandiri murni berdasarkan Blueprint yang diterima.  
**Consequences:** Menjamin determinisme kompilasi biner 100% dan menghilangkan kebocoran memori.
