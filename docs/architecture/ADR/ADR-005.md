# ADR-005: Segregation of Decision Engine and Solution Architect
**Status:** APPROVED  
**Date:** 2 Juli 2026  
**Context:** Pengambilan keputusan teknologi (seperti pemilihan database, frontend library, pola perakitan) sering kali dipadukan langsung dengan pembuatan model arsitektur sistem. Hal ini merusak prinsip tanggung jawab tunggal (*Single Responsibility*) dan menyulitkan perluasan generator plugin.  
**Decision:** Memisahkan proses kompilasi kognitif menjadi dua sub-lapisan independen:
1.  **Decision Engine:** Bertanggung jawab memilih strategi teknologi (*Technology Strategy*) seperti pemilihan React, Postgres, monolith vs microservices berdasarkan Blueprint logis.
2.  **Solution Architect:** Mengambil output keputusan teknologi tersebut dan menggambar/menyusun pola arsitektur fisik konkrit (*Architecture Model*).  
**Consequences:** Memungkinkan penambahan strategi teknologi baru tanpa merusak perumus arsitektur, meningkatkan fleksibilitas dan pemeliharaan kode generator.
