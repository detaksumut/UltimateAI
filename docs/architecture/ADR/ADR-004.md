# ADR-004: Generator Determinism by Default
**Status:** APPROVED  
**Date:** 2 Juli 2026  
**Context:** Penterjemahan dari spesifikasi kognitif universal menjadi artefak perangkat lunak fisik dapat menghasilkan variasi implementasi jika model generator bersifat adaptif tanpa batas. Ini merusak kemampuan penelusuran audit (*auditability*), verifikasi kepatuhan, dan reproduserabilitas build.  
**Decision:** UltimateAI Generator wajib bernilai deterministik secara baku (*deterministic by default*). Input yang sama wajib melahirkan hasil artefak fisik yang identik secara biner. Variasi implementasi (seperti pilihan pola mikroservis atau serverless) hanya diperbolehkan melalui profil generator (*generator profiles*) atau parameter konfigurasi eksplisit yang dicatat di Blueprint.  
**Consequences:** Menjamin keandalan sertifikasi biner (JPRC/UPCR) dan memudahkan penjejakan *bug/compliance errors*.
